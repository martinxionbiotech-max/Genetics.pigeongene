# 赛鸽遗传知识库

赛鸽遗传知识库（genetics.senopigeon.com）是 PigeonGene 数字生态的遗传学知识支撑站，为鸽友与育种者提供**科学、审慎**的赛鸽遗传学知识。

## 本站内容

- [基因百科](genes/index.md)：8 个性能相关基因位点的功能、研究证据与解读边界（LDHA、DRD4、CRY1、MSTN、LRP8、GSR、CASK、F-KER），每页标注证据等级与已验证文献来源；
- [遗传主题](topics/index.md)：育种遗传、性能遗传、归巢与耐力遗传、近交系数、羽色遗传等 12 个主题导读；
- [遗传标记](genetic-markers.md)：STR、SNP 等标记的类型、分型流程与局限性；
- [术语表](glossary.md)：核心遗传学术语解释；
- [常见问题](faq.md)：基因检测边界与解读的常见疑问。

## 谁适合阅读

- **鸽友**：理解基因检测报告里"可能关联"的含义，避免过度解读；
- **育种者**：了解近交系数、遗传力、选配策略背后的遗传学逻辑；
- **研究者**：追溯本站引用的文献来源（PMID/DOI 可核验）。

## 科学声明

> 基因关联均为**概率性、探索性**信息，表述一律使用"可能关联/研究提示"，**不构成**对比赛成绩的预测或保证。赛鸽实际表现受基因、训练、营养、健康与环境等多因素共同作用。

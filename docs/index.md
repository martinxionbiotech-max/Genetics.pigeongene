# 赛鸽遗传知识库

赛鸽遗传知识库（genetics.pigeongene.com）是 PigeonGene 数字生态的遗传学知识支撑站，为鸽友与育种者提供**科学、审慎**的赛鸽遗传学知识。

## 本站内容

- **8 大性能基因位点**：LDHA、DRD4、CRY1、MSTN、LRP8、GSR、CASK、F-KER
- **遗传标记**：STR、SNP、VNTR、InDel 的类型与分型流程
- **育种与性能遗传**：遗传规律、数量性状、选配策略
- **术语表**：20 个核心遗传学术语

## 科学声明

> 基因关联均为**概率性、探索性**信息，表述一律使用"可能关联/研究提示"，**不构成**对比赛成绩的预测或保证。赛鸽实际表现受基因、训练、营养、健康与环境等多因素共同作用。

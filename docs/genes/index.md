# 基因百科

本栏目收录赛鸽检测涉及的 8 个核心基因位点。每个页面介绍基因的生物学功能、在赛鸽中的角色、已发表研究的证据强度与解读边界，帮助鸽友理解「基因检测能说明什么、不能说明什么」。

| [F-KER](f-ker.md) | 羽毛角蛋白 · 多态性鉴定 | D |

## 证据等级说明

- **A**：多项独立研究一致支持；
- **B**：赛鸽专属研究、同行评审期刊、有统计意义；
- **C**：单项/初步鸽类研究；
- **D**：生物学合理，但鸽类赛鸽证据有限。

## 阅读建议

- 每页「研究证据」小节给出该基因可验证的文献来源；
- 「科学局限性」小节说明证据边界——基因型不构成成绩预测；
- 育种决策请结合赛绩、血统与多基因信息综合判断。

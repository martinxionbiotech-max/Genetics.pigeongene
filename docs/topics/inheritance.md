# 遗传规律

遗传规律描述遗传信息如何在世代间传递。孟德尔遗传定律是理解单基因性状遗传的基础，数量遗传学则解释复杂性状的遗传——两者合起来，才构成赛鸽遗传的完整图景。

## 通俗解读（打个比方）

遗传规律就像理解**"孩子像不像父母"**的规则书：

- **孟德尔定律**：解释"单个性状"怎么传——比如某个羽色性状，像"抛硬币"一样有规律地传给后代；
- **数量遗传学**：解释"综合表现"怎么传——比如飞行成绩，像"身高等多个因素混合"，不是非黑即白。

单个性状看孟德尔，综合表现看数量遗传。

## 孟德尔遗传定律

孟德尔通过豌豆杂交实验揭示了遗传的基本规律：

- **分离定律**：每个个体有两份等位基因，配子中只有一份；
- **自由组合定律**：不同基因座位的等位基因独立分配；
- **显性定律**：显性等位基因在杂合状态下表达。

这些定律适用于**单基因性状**（如部分羽色、伴性性状等）。

## 数量性状遗传

赛鸽飞行性能等复杂性状属于**数量性状**：

- 受多基因加性效应与环境共同影响；
- 表现为连续分布（如成绩有高有低，而非"有/无"）；
- 遗传分析比单基因性状复杂得多。

## 遗传力

遗传力衡量表型变异中由**遗传因素**解释的比例：

- 遗传力越高，通过选育改良性状的效率越高；
- 飞行性能的遗传力受测量方式与环境控制影响；
- 遗传力高 ≠ 环境不重要，二者共同决定最终表现。

## 关键要点

- 孟德尔定律解释单基因性状遗传，数量遗传学解释复杂性状；
- 飞行性能是数量性状，多基因+环境共同决定；
- 遗传力衡量遗传因素对变异的解释比例；
- 遗传力越高，选育改良效率越高。

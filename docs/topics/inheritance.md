# 遗传规律

遗传规律描述遗传信息如何在世代间传递。孟德尔遗传定律是理解单基因性状遗传的基础，数量遗传学则解释复杂性状的遗传。

## 孟德尔遗传定律

孟德尔通过豌豆杂交实验揭示了遗传的基本规律。

- 分离定律：每个个体有两份等位基因，配子中只有一份
- 自由组合定律：不同基因座位的等位基因独立分配
- 显性定律：显性等位基因在杂合状态下表达

## 数量性状遗传

赛鸽飞行性能等复杂性状属于数量性状，受多基因加性效应与环境共同影响，表现为连续分布。这类性状的遗传分析更复杂。

## 遗传力

遗传力衡量表型变异中由遗传因素解释的比例。遗传力越高，通过选育改良性状的效率越高。飞行性能的遗传力受测量方式与环境控制影响。

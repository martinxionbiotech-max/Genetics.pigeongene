# 基因型与表型

基因型是指个体携带的遗传信息，表型是基因与环境共同作用产生的可观察特征。理解两者关系是正确解读基因检测结果的关键。

## 什么是基因型

基因型是个体在特定基因位点上携带的等位基因组合。例如，某基因位点可能为 AA、Aa 或 aa 三种基因型之一。

## 什么是表型

表型是个体表现出的可观察特征，如羽色、体型、飞行速度等。表型由基因型与环境共同决定。

## 基因型到表型的距离

从基因型到表型之间存在复杂的中间过程，包括基因表达、蛋白功能、生理通路与环境交互。因此，基因型不能直接等同于表型。

- 基因型是遗传潜能的基础
- 表型是遗传与环境的共同结果
- 相同基因型可能产生不同表型
- 复杂性状受多基因影响

# 基因型与表型

基因型（genotype）是基因的组合，表型（phenotype）是观察到的性状。基因检测读取的是基因型，鸽友看到的是表型——理解两者的关系，是正确使用检测报告的前提。

## 通俗解读（打个比方）

基因型像**「剧本」**，表型像**「演出」**。同一个剧本（基因型），不同舞台、演员与排练条件（环境、训练、营养）下，演出效果（表型）可以很不一样。

## 基因型与表型的对应关系

- **单基因性状**：一对等位基因即可决定（如部分羽色性状），对应关系直接；
- **多基因性状**：赛绩、体型等受多基因加性效应控制，单点基因型只能提供部分信息；
- **表型可塑性**：同一基因型在不同环境下表型不同，是赛鸽「状态波动」的遗传学解释之一。

## 基因型 + 环境 = 表型

这是数量遗传学的基本公式。对赛鸽而言：

- 基因型提供**潜力上限**；
- 环境（训练、营养、健康、应激）决定**潜力的实现程度**；
- 基因型与环境的交互作用让个体表现更加复杂。

## 检测报告读的是什么

基因检测报告给出的是**标记位点的基因型**——个体在特定 SNP/微卫星位点上携带的等位基因组合。它回答的问题是「这只鸽子在某个位点上是什么型」，而不是「这只鸽子能飞多快」。

## 从基因型到决策

- 基因型用于**选配参考**：了解亲本的遗传背景，规划组合；
- 表型用于**成绩验证**：后代赛绩才是检验选配效果的最终标准；
- 两者滚动更新：好血统 + 好成绩 + 好基因型 = 更完整的育种信息。

## 常见误区

- 「基因型好 = 表型一定好」——忽略了环境与多基因交互；
- 「表型好 = 基因型一定好」——环境造就的「状态型」鸽子可能遗传基础一般；
- 「一次检测定终身」——检测是快照，育种是长跑。

## 常见问题

**基因型相同，为什么表型不同？**

环境差异、基因表达调控与随机发育波动都会造成表型分化。

**表型好的鸽子值得留种吗？**

赛绩是重要参考，但建议结合血统、近交背景与基因检测综合评估。

**检测报告能直接给出育种建议吗？**

报告提供基因型信息，育种决策仍需结合赛绩、血统与鸽舍实际条件。

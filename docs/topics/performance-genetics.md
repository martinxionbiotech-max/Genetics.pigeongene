# 性能遗传

性能遗传关注赛鸽竞翔表现背后的遗传基础。赛绩是复杂的数量性状，现代研究通过候选基因与基因组学方法逐步揭示其遗传构成。

## 通俗解读（打个比方）

竞翔成绩像**「一场综合考试」**：速度、耐力、定向、动机、恢复能力是不同科目，基因提供各科目的「基础分」，训练与状态决定「临场发挥」。没有单个基因是「满分科目」。

## 已研究的候选基因

同行评审研究报道了若干与竞翔表现存在统计关联的候选基因（关联 ≠ 因果，解读需谨慎）：

- **LDHA**：能量代谢相关，与竞翔存活率存在关联（Ramadan 2018, PLOS ONE）；
- **DRD4**：多巴胺信号相关，多态性与竞翔表现关联（Proskura 2015, Animal Genetics）；
- **CRY1**：昼夜节律相关，多态性与信鸽竞翔表现关联（Dybus 2021, Animals）；
- **LRP8 / GSR**：脂质代谢与抗氧化相关，多态性与竞翔表现关联（Kulig 2025, Int J Biol Macromol）。

详见 [基因百科](../genes/index.md) 各基因页的证据等级说明。

## 归巢与耐力的基因组学研究

基因组学研究提示归巢能力与能量代谢、神经发育等通路的遗传基础（Shao 2020, Mol Biol Evol）。这些研究为候选基因筛选提供背景，但距「用基因预测成绩」仍有很大距离。

## 性能遗传的复杂性

- **多基因**：性能受大量微效基因共同控制；
- **环境交互**：训练、营养、天气、赛事距离与基因型相互作用；
- **表型测量**：成绩受赛事条件与对手水平影响，测量本身有噪声。

## 常见误区

- 「测了性能基因就知道能不能飞」——关联研究提供概率信息，不是判决书；
- 「外国鸽子基因更好」——品种差异存在，但个体差异远大于群体标签；
- 「基因决定一切」——训练与管理对赛绩的贡献不可忽视。

## 常见问题

**哪个基因对赛绩最重要？**

目前没有公认的「最重要基因」。赛绩是多基因与环境共同作用的结果。

**基因检测能预测比赛名次吗？**

不能。检测提供遗传背景参考，名次由综合因素决定。

**性能基因检测对育种有什么用？**

作为选配的参考信息之一，与赛绩、血统结合使用，避免单一因素决策。

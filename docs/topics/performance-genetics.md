# 性能遗传

性能遗传学研究速度、耐力、归巢能力等飞行性能性状的遗传基础。这些性状多为复杂的数量性状，是赛鸽育种与基因检测的核心关注点。

## 通俗解读（打个比方）

性能就像赛鸽的**"综合考试成绩"**：

- 不是某一科（单个基因）决定的，而是许多科（大量基因）共同算出的总分；
- 还受"临场发挥"（训练、营养、天气）影响；
- 基因检测，就像考前拿到一份"天赋倾向测评"——能提示哪些科目有潜力，但**不是最终成绩单**。

## 性能性状的遗传特性

飞行性能是复杂的数量性状，具有以下特征：

- **多基因控制**：多个基因共同作用，每个贡献有限；
- **环境敏感**：受训练、营养、健康影响大；
- **连续分布**：个体间表现呈连续变化，而非"有/无"；
- **遗传力有限**：遗传因素只解释部分变异，环境同样重要。

## 速度与耐力

速度与耐力是两类不同的性能维度：

- **短距离速度**：更依赖无氧代谢与爆发力（相关基因如 LDHA）；
- **长距离耐力**：更依赖有氧代谢与能量储备（相关基因如 LRP8、GSR、MSTN）。

两者对应的生理通路与候选基因各有侧重，选育时应明确目标。

## 基因标记的参考价值

与性能相关的基因标记（如 LDHA、MSTN、LRP8 等）提供遗传倾向的参考信息，但**不应被理解为成绩的决定因素**。前瞻性研究已证实，基因对成绩的贡献是概率性的。

## 关键要点

- 性能是复杂数量性状，多基因+环境共同决定；
- 速度与耐力对应不同的生理通路与候选基因；
- 基因标记提供倾向参考，非成绩决定因素；
- 选配应结合赛绩、血统与多基因信息综合判断。

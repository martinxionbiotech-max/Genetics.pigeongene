# 性能遗传

性能遗传学研究速度、耐力、归巢能力等飞行性能性状的遗传基础。这些性状多为复杂的数量性状。

## 性能性状的遗传特性

飞行性能是复杂的数量性状，具有以下特征：

- 多基因控制：多个基因共同作用
- 环境敏感：受训练、营养影响大
- 连续分布：个体间表现呈连续变化
- 遗传力有限：遗传因素只解释部分变异

## 速度与耐力

速度与耐力是两类不同的性能维度。短距离速度更依赖无氧代谢与爆发力，长距离耐力更依赖有氧代谢与能量储备。相关基因位点也各有侧重。

## 基因标记的参考价值

与性能相关的基因标记（如 LDHA、MSTN、LRP8 等）提供遗传倾向的参考信息，但不应被理解为成绩的决定因素。

# 归巢遗传

归巢能力是赛鸽最珍贵的性状之一。归巢遗传学研究导航、空间记忆与归巢倾向背后的遗传因素。

## 归巢能力的复杂性

归巢涉及空间定位、方向判断、记忆与动机驱动等多个环节，是高度复杂的神经行为。它受多基因与环境经验共同影响。

## 相关基因

研究提示，部分与神经行为相关的基因可能与归巢能力存在关联。

- DRD4：多巴胺受体，与认知行为相关
- CRY1：隐花色素，与节律与时间感知相关
- CASK：突触功能，与神经稳定性相关

## 科学态度

归巢能力尚无单一的"归巢基因"。现有基因与归巢的关联多为探索性研究，需谨慎解读。

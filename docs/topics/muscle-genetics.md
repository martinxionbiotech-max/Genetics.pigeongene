# 肌肉遗传

肌肉遗传学研究赛鸽肌肉发育、力量与质量的遗传基础。飞行依赖胸肌与翼肌的持续做功。

## 肌肉与飞行

胸肌是赛鸽飞行的主要动力来源。肌肉质量、力量与耐力直接影响飞行能力。

## 相关基因

肌肉发育相关的基因位点包括：

- MSTN：肌肉生长抑制素，负调控肌肉生长
- LDHA：能量代谢，影响肌肉供能

## 肌肉性状的遗传

肌肉性状受遗传与训练共同影响。基因标记提供遗传倾向参考，训练是发挥肌肉潜能的关键。

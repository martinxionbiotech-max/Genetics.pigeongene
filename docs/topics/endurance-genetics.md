# 耐力遗传

耐力遗传学研究赛鸽持续飞行能力的遗传基础。长距离飞行高度依赖能量代谢、肌肉耐力与抗氧化能力。

## 耐力的生理基础

长距离飞行的耐力表现依赖于：

- 高效的脂肪能量代谢
- 良好的肌肉耐力与力量
- 强大的抗氧化与恢复能力
- 稳定的能量储备

## 相关基因

多个基因位点与耐力相关的生理过程有关。

- MSTN：肌肉发育与耐力
- LRP8：能量代谢与脂肪酸利用
- GSR：抗氧化与应激恢复
- LDHA：能量代谢

## 科学局限

耐力是复杂的数量性状，受多基因、训练与营养共同影响。基因标记仅提供遗传倾向参考。
